# Instagram Unfollowers PRO v8.8.1

GitHub Releases last shipped **v8.5.1**. This tag includes everything since then: the suite home, Meta tools, and the Time Machine polish.

## English

### Highlights

- **🏠 Suite home** — Analyze, Clean, Grow, History instead of a stack of buttons.
- **📂 Offline Meta scan** — `following.html` + `followers_*.html`, zero Instagram requests.
- **🧹 Pending requests** — cancel outgoing follows from a Meta export; progress stays local.
- **📋 Clean lists** — recently unfollowed, blocked, recent requests (read-only).
- **↔️ Community diff** — compare two exports (who left, who you followed, new mutuals).
- **⏳ Time Machine** — letter avatars when there is no photo; mass cancels collapse into a daily summary so they never wipe the 1000-event cap; filters for detected / unfollowed / cancelled.
- **🐛 Fixes** — Ghost/CSV/PDF labels, live “NEW” = they stopped following you, incomplete scans no longer overwrite the snapshot, failed pending lookups stay retryable, whitelist matches username across Meta and live.

### Still beta / free

- **Growth Engine** remains beta until manual Instagram QA.
- **All PRO features unlocked** while we migrate payment providers.

### Install

1. Download `dist.zip` below → Load unpacked in `chrome://extensions`
2. Or use the [landing page](https://edvincodes.github.io/InstagramUnfollowers/) Copy Script / Mobile Bookmarklet (`content.js?v=8.8.1` after Pages deploys)
