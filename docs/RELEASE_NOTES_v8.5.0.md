# Instagram Unfollowers PRO v8.5.0

## English

### Highlights

- **Lightweight bookmarklet loader (~300 bytes)** — Copy Script no longer tries to stuff ~1MB of JS into a `javascript:` URL. The tiny `loader.js` fetches the full app from GitHub Pages on `instagram.com`.
- **Landing polish** — “3 Ways to Run” (extension / console / mobile bookmarklet), drag-to-bookmarks button, PRO vs basic comparison table, pricing section heading, Guides section.
- **SEO guides**
  - [Ghost Score Explained](https://edvincodes.github.io/InstagramUnfollowers/ghost-score.html)
  - [How to Detect Instagram Bots (2026)](https://edvincodes.github.io/InstagramUnfollowers/detect-instagram-bots.html)
- **Docs** — Chrome Web Store listing prep, analytics setup notes, payment provider migration notes.
- **Quality** — ESLint clean on Growth Engine code; build / tsc / vitest green.

### Still beta / free

- **Growth Engine** remains beta until manual Instagram QA.
- **All PRO features unlocked** while migrating payment providers (Lemon Squeezy declined this category).

### Install

1. Download `dist.zip` below → Load unpacked in `chrome://extensions`
2. Or use the [landing page](https://edvincodes.github.io/InstagramUnfollowers/) Copy Script / Mobile Bookmarklet
